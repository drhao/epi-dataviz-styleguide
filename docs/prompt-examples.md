# 給 AI 工具的 Prompt 範例

> 想請 AI 幫你畫疫情圖表，又希望它自動遵守本指引？這份文件提供現成的 prompt 模板，**直接複製貼上、填空換成你的資料即可**。

## 兩種使用情境

| 情境 | 適用工具 | 特點 |
|------|---------|------|
| 🤖 **A. 已安裝 skill 的 AI** | Claude Code、Codex、Google Antigravity 等本地 agent | AI 會自動讀取 SKILL.md，prompt 可以較簡短 |
| 🌐 **B. 一般網頁 AI** | ChatGPT、Claude.ai、Gemini 網頁版 | 需在 prompt 中內嵌指引核心規範 |

不確定自己屬於哪一種？**辦公室電腦上用 Claude Code 跑指令的，是 A；網頁打開對話框聊天的，是 B。**

## 🤖 情境 A：已安裝 skill 的 AI

### 前提

你的 AI 工具已將本 repo 的 `skill/` 資料夾安裝為 skill（詳見 [`skill/SKILL-README.md`](../skill/SKILL-README.md)）。

### 通用 prompt 模板

```
我有 [資料來源／附檔]，內容是 [簡短說明資料內容]。

請依本組織的「疫情資料視覺化指引」幫我畫一張 [圖表類型]，
重點是凸顯 [想傳達的訊息]。

技術需求：
- 程式語言：Python（matplotlib）
- 輸出：高解析度 PNG
- 中文字體
```

AI 會自動：

- 讀取 SKILL.md 與對應的 reference 規範
- 從 `epidemic_palette.py` 載入色票
- 套用 `apply_style()` 標準樣式
- 選擇正確的圖表類型與配色模式

### 具體場景範例

#### 場景 A1：每日新增確診圖

```
這是過去 28 天的每日確診數 CSV：[附檔 / 貼上資料]。

請依組織的疫情視覺化指引畫一張每日新增直條圖 + 7 日移動平均，
重點是讓讀者看出週末填報延遲的真實波動，不要把週末資料平滑掉。

輸出 Python 程式碼 + 執行後的 PNG。
```

#### 場景 A2：變異株消長 100% 堆疊

```
附檔是過去 6 個月各變異株的每週比例（已加總為 100%）。

請按指引畫一張 100% 堆疊長條圖，呈現 JN.1、KP.2、KP.3、LB.1 的消長。
不要用圓餅圖（即使只看一個月），多月份的比例變化必須能跨期比較。
```

#### 場景 A3：縣市發生率排名

```
這是 22 縣市的每 10 萬人口發生率資料：[附檔]。

請畫一張水平排名長條圖，由大到小排序。
超過 800 的縣市請用 Terracotta 標示（非 Alert Red,避免過度警示）。
資料標籤直接標於長條右端，可省略 X 軸刻度。
```

#### 場景 A4：年齡 × 性別人口金字塔

```
請從 sample-data/10-age-gender.csv 讀取資料,畫一張確診者年齡 × 性別的人口金字塔。
注意 X 軸要顯示絕對值（左右兩側都正值,中央為 0）。
```

#### 場景 A5：散佈圖找相關性

```
這是 20 個縣市的疫苗接種率 vs. 重症率資料：[附檔]。

請畫散佈圖呈現兩變數的相關性,加上趨勢線並標註相關係數。
泡泡大小表示縣市人口（萬人）。
```

## 🌐 情境 B：一般網頁 AI

### 通用 prompt 模板

把以下完整 prompt **整段複製**到 ChatGPT、Claude.ai、Gemini 等網頁 AI：

```
你是公部門資料視覺化助手。請依下列「疫情資料視覺化指引」幫我畫圖。

【核心原則】
1. 清晰優先:每個視覺元素必須服務於訊息,移除 3D、過度網格、不必要陰影
2. 誠實呈現:Y 軸從零開始,不截斷座標軸誤導比例
3. 一致性:相同指標跨圖使用相同顏色
4. 負責任溝通:紅色僅用於警示,不可作一般類別配色

【色彩系統】
- 主色(Sage Green):#739A6D
- 類別配色順序(綠→藍→黃→鴨綠→銅→梅):
  #739A6D, #587A9D, #C8A041, #49888D, #916E46, #955F71
- 折線專用加深版:
  - 主色折線:#5D7F58(主色 500 對白底對比僅 3.2,折線需用更深版)
  - Mustard 折線:#A8821F(原色對比不足)
- 強調色家族(僅警示用):
  - Alert Red: #BE373C(最強警示)
  - Terracotta: #B5584A(次強)
  - Caution Amber: #D2962D(注意)
- 中性色:#A2ABA0(對照線)、#444C43(正文)

【圖表規範】
- 直條圖 Y 軸必須從零;一般 width=0.6,密集每日時序 width=0.75
- 折線圖主線寬 2.5-3px,對照線 1.5px(常用虛線)
- 移動平均用 trailing 7 日(i 日 = i-6 到 i 平均,本日含前 6 日)
- 圓餅圖僅在 2-4 類且差異≥5% 時用,否則改水平堆疊條
- 移除頂部右側邊框,僅顯示 X/Y 軸線
- 預設只顯示水平格線(直條/折線),散佈圖才用雙向格線
- 已標數值的長條圖可省略 Y 軸刻度

【需求】
我的資料:[簡述資料內容,或貼上 CSV 前 5 行]
我想呈現:[想傳達的訊息]

請用 Python(matplotlib)畫出符合上述規範的圖表,
並支援中文字體(Noto Sans TC 或 Noto Sans CJK)。
```

### 精簡版（資料簡單時用）

```
請依以下規範用 Python matplotlib 畫圖:
- 主色 #739A6D(Sage Green),類別配色:#587A9D, #C8A041, #49888D
- 紅色僅警示用,不作一般類別色
- Y 軸從零開始,移除頂部右側邊框
- 中文字體支援
- 折線寬 2.5px,長條 width=0.6

資料:[貼上]
我要:[簡述需求]
```

## 常見問題

### Q：AI 畫出來的圖沒套用色彩規範怎麼辦？

**情境 A**：確認 skill 已正確安裝。在 prompt 中可加一句「請先讀 SKILL.md 確認規範」。

**情境 B**：用上面的「通用 prompt 模板」完整版,規範要寫進 prompt 才行。也可以追問「請改用 #739A6D 主色重畫」。

### Q：AI 畫的圖能直接拿來發布嗎?

**不建議直接發布。** 即使 AI 套用了規範,仍應由人類檢查:
- 資料準確性(AI 可能誤讀資料)
- 訊息傳達是否清晰
- 是否需要加上資料來源、註腳
- 對外發布前的政治／公衛敏感度

### Q：可以用其他語言畫嗎？(R、JavaScript)

可以,把 prompt 中的「Python(matplotlib)」改成「R(ggplot2)」或「JavaScript(Chart.js)」即可。色彩 HEX 是通用的。

### Q：如果 AI 不理解疫情圖表的特殊規範?

特別敏感的圖表（如警戒線、波次比較、變異株消長）建議:

1. **先看 [`skill/references/`](../skill/references/) 對應規範**理解你要的細節
2. 在 prompt 中明確指出特殊需求,例如:
   - 「不要把確診直條全部標紅,僅將超過警戒值部分標紅」
   - 「使用 trailing 7 日移動平均,前 6 天用自適應窗口」
   - 「波次比較時當前波加粗,歷史波用淺灰」
3. 必要時直接附上對應的 reference markdown 給 AI 參考

## 進階：構建自己的 prompt

如果上述模板都不適用,寫自訂 prompt 時請涵蓋以下要素:

| 要素 | 範例 |
|------|------|
| **角色設定** | 「你是公部門資料視覺化助手」 |
| **規範來源** | 「依組織的疫情視覺化指引」或內嵌核心規範 |
| **資料說明** | 提供資料的內容、單位、時間範圍 |
| **核心訊息** | 「重點是凸顯 XX」 |
| **特殊處理** | 「紅色僅標警戒值,不可標一般長條」 |
| **技術需求** | 程式語言、輸出格式、字體支援 |

prompt 越具體,AI 產出的圖越接近預期。**模糊的 prompt 會得到模糊的圖。**
