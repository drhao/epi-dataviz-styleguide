# 疫情資料視覺化指引

> Epidemic Data Visualization Guideline · Version 1.0 · 2026
> Public Sector Edition

本指引提供組織內所有疫情資料分析、流行病學報告、儀表板與對外公告製作視覺化時的色彩、圖表與設計準則。考量疫情資訊的高敏感度，特別規範紅色僅用於強調與警示，避免過度引發公眾焦慮。

## 1. 核心原則

| # | 原則 | 說明 |
|---|------|------|
| 001 | **清晰優先** | 每一個視覺元素都必須服務於訊息。移除所有不傳達資訊的裝飾（chartjunk）：3D 效果、過度的網格線、不必要的陰影。 |
| 002 | **誠實呈現** | Y 軸原則上從零開始；不截斷座標軸誤導比例；不刻意挑選有利的時間區間。資料的真實性高於敘事的戲劇性。 |
| 003 | **一致性** | 同一份報告中，相同指標使用相同顏色；類別順序與配色跨頁面一致；單位、時間格式、四捨五入規則統一。 |
| 004 | **負責任溝通** | 疫情資料涉及公眾情緒。紅色不可濫用於一般類別配色，僅在標示警示閾值、關鍵異常時使用。 |

> **核心問題**：「這個視覺呈現會讓民眾正確理解風險，還是會放大／低估風險？」資料誠實永遠優先於敘事衝擊力。當不確定時，預設選擇較克制的版本。

## 3. 類別配色與強調色

### 3.1 類別配色（依優先順序）

只需 N 色時，取前 N 個。**最多 6 色**，超過建議合併。

| 順序 | 名稱 | HEX | 適用 |
|------|------|-----|------|
| 1 | Sage（主色） | `#739A6D` | 主要對象、本機關、本國 |
| 2 | Slate Blue | `#587A9D` | 第二類別 |
| 3 | Mustard | `#C8A041` | 第三類別（折線用深版 `#A8821F`） |
| 4 | Teal | `#49888D` | 第四類別 |
| 5 | Bronze | `#916E46` | 第五類別 |
| 6 | Plum | `#955F71` | 第六類別 |

### 3.2 強調色家族（紅／橙系）

**不得作為一般類別色使用。** 一張圖中強調色出現的元素應少於 20%。

| 強度 | 名稱 | HEX | 使用情境 |
|------|------|-----|----------|
| 🔴 最強 | Alert Red | `#BE373C` | 超過警戒值、危險、新增高峰 |
| 🟠 次強 | Terracotta | `#B5584A` | 次強警示、發散色階負端、強對比 |
| 🟤 柔和 | Clay | `#B87B61` | 柔和強調、長期趨勢的反向指標 |
| 🟡 提醒 | Caution Amber | `#D2962D` | 接近閾值、注意 |

> **⚠ 疫情情境特別注意**：紅色在公共衛生溝通中具有強烈情緒效應。**勿用紅色標示確診數的長條本身**——即使數字很高，紅色化會放大恐慌感受。建議做法：長條本身使用中性色或主色，**僅將「超過警戒閾值的部分」或標示線標為紅色**。

## 4. 配色搭配模式

選擇順序：

① 序列**有自然順序**(嚴重度、年齡、波次、劑次)？→ **E(單色色階)**
② 只有 **2-3 組類別且想克制視覺**？→ **E(單色色階)**
③ 要凸顯某對象嗎？→ A 或 D
④ 多類別、無焦點？→ C
⑤ 兩主對象 + 一基準？→ B

**不確定時用 A。**

### 4.1 模式 A — 主色 + 中性對照

最常用、最有焦點感的搭配。**當你要凸顯「某一個對象」時使用。**

```
焦點：#739A6D（或折線用 #5D7F58）
對照：#A2ABA0（Neutral 400，常用虛線）
```

適用：折線對照（本機關 vs. 平均）、雙條比較、本波 vs. 歷史波次

### 4.2 模式 B — 主色 + 主色 + 中性對照（2 主 1 灰）

比較「兩個主要對象」並保留基準。

```
主指標 1：#739A6D
主指標 2：#587A9D（或其他 cat 色）
基準：#A2ABA0
```

適用：本國 vs. 鄰國 vs. 全球平均；陽性 vs. 陰性 + 未受檢

### 4.3 模式 C — 純類別配色

所有類別**地位平等、無焦點對象**時使用，依優先順序使用 cat-1 到 cat-N。

適用：三變異株比例、輕／中／重症、四大主要變異株

### 4.4 模式 D — 類別配色 + 強調

多類別中**有一個需要警示**時使用。

```
一般：cat-1, cat-2, ...
警示：Alert Red 或 Terracotta
```

適用：縣市排名中超過閾值者標紅、變異株中新出現的高關注株

### 4.5 模式 E — 單色色階（序數或少類別）

兩種情境適用：

1. **序數資料**——序列彼此有自然順序（嚴重度、年齡、時期、劑次），以明度反映程度
2. **2-3 組類別**——即使無自然順序,類別數少時用單色更克制,讓視覺聚焦資料形狀

```
2 序列(焦點+對照):  #496345 + #CACFC9
3 序列(輕/中/重):    #B4C9B1 → #739A6D → #374C34
4 序列(歷次波次):    #D1DECF → #91B08C → #5D7F58 → #374C34
5–7 序列:           MONOCHROME["scale_N"]
```

**核心規則**：序數情境下,色階方向必須對應「弱 → 強」、「過去 → 現在」、「淺 → 重」。

| 情境 | 適用模式 | 為什麼 |
|------|--------|--------|
| 嚴重度（輕/中/重）| ✓ 模式 E | 序數,深淺對應強度 |
| 疫苗 1/2/3 劑 | ✓ 模式 E | 序數遞進 |
| 歷次波次比較 | ✓ 模式 E | 時序,當前波最深 |
| 男 vs 女 | ✓ 模式 E | 2 類別,克制視覺 |
| 本機關 vs 平均 | ✓ 模式 E | 焦點+對照 |
| 變異株 6 種 | ✗ 模式 C | 並列無序、類別多 |
| 各縣市 22 個 | ✗ 模式 A 或 C | 類別太多 |
| 不同部門 6 個 | ✗ 模式 C | 並列無序、地位平等 |

**判斷標準**：
1. 序數資料？→ 模式 E
2. 2-3 組類別 + 想克制視覺？→ 模式 E
3. 6+ 類別且無序？→ 模式 C
4. 類別需要「對立感」？→ 模式 C

**堆疊時**：最深色放底部,作為視覺基底。

## 5. 序列與發散色階

### 5.1 序列色階（單向：低 → 高）

用於有明確高低的數值：人口密度、預算規模、完成率。

```
#F1F5F0 → #D4E0D2 → #AEC5AB → #8BAC86
→ #6A9164 → #506D4B → #354832
```

### 5.2 發散色階（雙向：負 ← 中 → 正）

用於有自然中點的資料：預算差額、滿意度、人口變動。

```
#476043 ← #71936C ← #B2BFB0 ← [#F2F3F2] → #D8C5C0 → #BC8776 → #965440
```

> **重要**：中間色不可使用純白，否則零值會被誤認為「無資料」。本指引採用淺灰綠 `#F2F3F2` 作為中性過渡色。

## 8. 圖表選用

| 疫情分析問題 | 建議圖表 | 適用時機 | 避免使用 |
|------------|---------|---------|---------|
| 每日新增 | 直條圖 + 7 日移動平均線 | 確診／死亡／檢驗數 | 純折線；面積堆疊 |
| 長期趨勢 | 折線圖、區域圖 | 數週到數月走向 | 直條圖（> 30 點時擁擠） |
| 同期比較 | 折線 + 歷史範圍填色帶 | 今年 vs 去年同期 | 並排兩根長條 |
| 地區比較 | 水平長條圖、面量圖 | 22 縣市發生率（須標準化） | 未標準化的絕對數 |
| 變異株／疫苗組成 | 100% 堆疊長條 | 病毒株消長 | 圓餅圖 |
| 年齡／性別分布 | 人口金字塔、分組長條 | 高風險族群分析 | 圓餅圖；3D 圖 |
| 單一時點組成 | 水平堆疊條（首選）、圓餅（條件使用） | 類別 2–4 個 | 3D 圓餅；>4 類圓餅 |
| 關鍵指標 | 大數字、KPI 卡 | 儀表板首屏 | 儀表盤 gauge |
| 超額死亡 / 基準對照 | 折線 + 對照基準線 / 陰影區間 | 與歷年平均比較 | 單獨呈現實際值 |
| 傳播鏈／關聯 | 散布圖、網絡圖 | 探索變數相關性 | 折線（暗示時間順序） |

## 9. 圖表規範

### 9.1 直條圖比例

`barPercentage × categoryPercentage` ＝ 條寬佔類別槽的比例（Chart.js）。

| 圖表類型 | barPercentage | categoryPercentage | matplotlib width |
|---------|--------------|--------------------|-----------------|
| 單組直條 | 0.55 | 0.85 | 0.6 |
| 密集時序直條（每日） | 0.75 | 0.9 | 0.75 |
| 堆疊直條 | 0.6 | 0.85 | 0.65 |
| 分組直條 | 0.85 | 0.75 | n/a |
| 水平排名長條 | 0.7 | 0.85 | 0.7 |

### 9.2 折線圖配色（重要）

折線比長條纖細，**同樣顏色畫成折線會明顯偏淺**。建議使用加深版：

| 用途 | 長條圖／填色 | 折線圖建議 |
|------|-------------|-----------|
| 主要序列 | `#739A6D`（500） | **`#5D7F58`**（600） |
| 第二序列 | `#587A9D` | `#587A9D` 同色 |
| 第三序列 | `#C8A041` | **`#A8821F`**（加深） |
| 對照／背景線 | `#A2ABA0` | `#A2ABA0` |

**增強折線可讀性的 5 項技巧：**

1. **加粗線寬**：主要 2.5–3px、次要 2px、對照 1.5px
2. **標示資料點**：起點、終點、極值處加 4–5px 圓點
3. **區分線型**：對照線用虛線 `borderDash:[5,4]`
4. **直接標籤**：在線條末端加類別名稱，移除圖例
5. **填色輔助**：單線圖加 20–25% 透明填色

### 9.3 7 日移動平均

- **使用「中心對齊」**（i 日 MA = i-3 到 i+3 平均），不用「向後看」（trailing）。中心對齊與當日資料視覺對齊，更直觀
- **資料區間至少 3 週（21+ 天）**才能有意義
- **兩端 3 天使用自適應窗口**（例如第 1 天用 1–4 天平均），避免折線斷掉
- **均線顏色**：用主色深版 `#374C34`（p-800），與淺色長條形成層次

```python
def centered_ma(data, window=7):
    half = window // 2
    return [
        round(sum(data[max(0,i-half):min(len(data),i+half+1)]) /
              (min(len(data),i+half+1) - max(0,i-half)))
        for i in range(len(data))
    ]
```

### 9.4 圓餅圖（條件使用）

**僅當所有條件成立時使用：**
- 類別 2–4 個
- 總和為 100%
- 單一時點，無需跨期比較
- 切片差異 ≥ 5%

**否則優先用水平堆疊條。** 使用圓餅時必須：
- 直接標籤（類別 + 百分比）標於切片旁，不依賴圖例
- 不使用 3D 效果
- 切片由大至小，從 12 點方向順時針
- 用類別配色順序，不為視覺效果採用高飽和色

## 10. Do & Don't

### Y 軸起點

| ✓ DO | ✗ DON'T |
|------|---------|
| 長條圖 Y 軸從零開始 | 截斷 Y 軸製造誇張差異 |
| 比較的是「長度」，截斷會嚴重誤導 | 從 90 開始的長條圖會讓 95 看起來像 100 的一半 |

### 顏色焦點

| ✓ DO | ✗ DON'T |
|------|---------|
| 用顏色凸顯焦點 | 為每根長條配不同顏色 |
| 重點對象主色，其餘中性灰 | 多色反而成為視覺噪音 |

### 圖表簡潔

| ✓ DO | ✗ DON'T |
|------|---------|
| 移除多餘的圖表元素 | 堆疊裝飾性元素 |
| 頂部右側邊框、過密網格線、3D 都應移除 | 邊框、背景、密集網格、陰影、3D 都是 chartjunk |

## 11. 無障礙

所有產出均應符合 **WCAG 2.1 AA 標準**。

### 11.1 對比度檢核

| 樣本 | 背景 | 對比 | 等級 | 用途 |
|------|------|------|------|------|
| Sage 500 文字 | 白 | 3.20 | AA Large | 僅大字級（18px+ 或 14px+ Bold） |
| Sage 600 文字 | 白 | 4.52 | AA | 正文 |
| Sage 700 文字 | 白 | 6.66 | AA | 強調 |
| Sage 800 文字 | 白 | 9.7 | AAA | 標題 |
| 白字於主色 | Sage 500 | 4.72 | AA | 按鈕、標籤 |

### 11.2 色覺友善原則

**不單獨以顏色傳達訊息。** 同時使用：

- **形狀／圖示**：折線資料點用不同形狀（圓、方、三角）
- **紋路**：黑白列印時可用斜線、點狀填充
- **直接標籤**：能標在資料旁的，不要放在圖例中

本指引的類別配色已通過三種主要色覺類型測試（紅色盲 Protanopia、綠色盲 Deuteranopia、藍色盲 Tritanopia）。

### 11.3 其他原則

- 圖表須提供**替代文字**，描述關鍵發現而非外觀
- 互動式圖表須支援**鍵盤操作**
- 提供**資料表格**作為圖表替代呈現

## 命名慣例

- **主色階**：`primary-50` ~ `primary-900`
- **中性色**：`neutral-50` ~ `neutral-900`
- **類別色**：`cat-1` ~ `cat-6`（依優先順序）
- **強調色**：`alert` / `terracotta` / `clay` / `caution`
- **折線專用**：`line-primary` / `line-mustard`
- **語意色**：`success` / `warning` / `danger` / `info`
