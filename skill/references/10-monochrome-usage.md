# 10. 單色使用情境（Monochrome）

> 用**主色階**（同色相、不同明度）取代類別配色，適用於「顏色不傳達類別差異」的情境。

## 為何使用單色情境

類別配色（綠藍黃...）會強烈暗示「這些是不同的東西」。但很多時候我們不需要這種強對比——**想讓讀者聚焦在資料形狀本身**，而非辨識色塊歸屬。此時單色色階比類別配色更克制、更有層次感。

| 用類別配色（不同色相） | 用單色色階（同色相不同明度） |
|------|------|
| 強調「這些彼此無關」 | 強調「這些可以一起讀」 |
| 視覺重點：色塊區分 | 視覺重點：資料形狀 |
| 多種色相→豐富/活潑 | 同色階→克制/聚焦 |
| 適合：縣市、變異株、業務類型 | 適合：序數、少量類別、層次比較 |

**單色不限於序數資料**——只要序列數量在 2–5 組之間，且你不想讓「色彩本身搶戲」，單色色階通常比類別配色更合適。色相數越少，圖表整體越克制、越好讀。

---

## 適用情境

### 1. 序數類別（有自然順序）— 最強烈推薦

色階方向直接對應「弱 → 強」、「過去 → 現在」，無需額外解讀：

- **嚴重度**：輕症 → 中症 → 重症 → 極重症
- **年齡層**：0–9, 10–19, ..., 80+
- **教育程度**：國小、國中、高中、大學、研究所
- **發病天數**：1–3 天、4–7 天、8–14 天、15+ 天

### 2. 時序比較

- **歷次波次**：第一波、第二波、第三波、當前波（當前波最深）
- **季別**：Q1、Q2、Q3、Q4
- **本年 vs 歷年**：今年最深、歷年由近至遠漸淺

### 3. 同主題的多指標

- **疫苗劑次**：第 1 劑、第 2 劑、第 3 劑、追加劑（累計接種的不同階段）
- **追蹤天數**：5 日、10 日、20 日、30 日累積數
- **百分位數**：P25、P50、P75、P90

### 4. 少量類別（2–3 組）+ 想克制視覺

即使類別**沒有自然順序**，只要數量少、且不希望色彩本身搶戲，單色仍是好選擇：

- **男 vs 女**：本身無順序,但只有 2 組,單色 + 不同明度即可區分
- **本機關 vs 同類機關平均**：focus + reference 配對
- **市區 vs 郊區**：地理分組但不需要色相對立
- **A 方案 vs B 方案 vs C 方案**：3 種方案的比較,用 scale_3 即可

**判斷**：問自己「這幾個類別**需要強調差異性嗎**？」
- 需要 → 類別配色
- 不需要,想呈現「整體脈絡」→ 單色

### 5. 焦點 + 對照

- **本機關 vs 其他**：本機關用深色,其他用淺色
- **本年 vs 歷年**：今年深主色,歷年淺主色

### 6. 強度遞進的分組

- **風險等級**：低風險、中風險、高風險、極高風險
- **數量區間**：< 100、100–500、500–1000、1000+

---

## 不適用情境

只有兩種狀況**不適合**單色色階：

### 1. 類別數 > 5

明度差不夠分辨。6 色以上請改用：
- 類別配色（CATEGORICAL）—— 若類別並列無序
- 熱力圖或序列色階 —— 若資料連續或可合併區間
- 拆成多個小圖（small multiples）—— 若必須分別顯示

### 2. 各類別必須強調「彼此截然不同」

例如：
- ✗ 不同變異株並陳對抗（JN.1 vs KP.2 是「對立的勢力」）→ 用 CATEGORICAL
- ✗ 6 個業務部門平等並列 → 用 CATEGORICAL
- ✗ 報告中本就有「組織色彩識別」對應特定類別 → 沿用既有配色

---

## 預設組合（Python 模組）

`epidemic_palette.py` 提供了 6 組常用單色組合：

```python
from epidemic_palette import MONOCHROME

MONOCHROME["focus_2"]    # 2 序列:焦點 + 對照（深綠 + 中性灰）
MONOCHROME["scale_3"]    # 3 序列:淺 → 中 → 深
MONOCHROME["scale_4"]    # 4 序列:細緻 4 階
MONOCHROME["scale_5"]    # 5 序列:5 個年齡層、5 個區間
MONOCHROME["scale_6"]    # 6 序列:完整年齡帶
MONOCHROME["scale_7"]    # 7 序列:一週、7 個年齡組
```

選擇邏輯：**有幾個序列就選對應的 scale_N**。超過 7 個序列時建議改用熱力圖或合併類別。

---

## 規範重點

### 1. 永遠由淺至深對應「弱→強」、「過去→現在」

色階方向必須有意義：
- ✓ 輕症（淺）→ 重症（深）
- ✓ 第一波（淺）→ 當前波（深）
- ✓ 第 1 劑（淺）→ 第 3 劑（深）
- ✗ 反向會造成讀者誤解

### 2. 色階之間必須有清楚對比

如果使用 6 個序列，6 個色階之間視覺上要能清楚區分。`MONOCHROME["scale_6"]` 已經設計過跳階——不是均勻地從 50 到 900，而是**重點在「中段」拉開差距**（避免淺色互相黏在一起）。

不要自己組「均勻分佈」的色階：

```python
# ✗ 6 階均勻（淺色彼此難分）
bad = ["#F6F9F6", "#E8EEE7", "#D1DECF", "#B4C9B1", "#91B08C", "#739A6D"]

# ✓ 本指引建議（中段拉開）
good = MONOCHROME["scale_6"]
```

### 3. 焦點對象使用最深色 + 線寬加粗

當有「需強調的對象」時（如當前波、本機關）：
- 色：使用色階中**最深**那一格
- 線寬：比其他粗 0.5–1px
- 標記點：只在焦點線上加 marker

```python
mono4 = MONOCHROME["scale_4"]
for vals, color, is_focus in zip(series_list, mono4, focus_flags):
    ax.plot(x, vals, color=color,
            linewidth=3 if is_focus else 1.8,
            marker="o" if is_focus else None)
```

### 4. 直接標籤優於圖例

單色色階的最大優點是視覺克制,但圖例小色塊（約 20×10 px）在白底上,淺色 swatch 對比往往不足。**改用直接標籤更清楚**：

```python
# 在最後一根長條右側標註類別名稱,取代圖例
last_x = len(categories) - 1
ax.text(last_x + 0.45, severe[-1]/2, "重症",
        va="center", fontsize=10, color=NEUTRAL["700"], fontweight="bold")
ax.text(last_x + 0.45, severe[-1] + moderate[-1]/2, "中症",
        va="center", fontsize=10, color=NEUTRAL["700"])
# ...
ax.set_xlim(-0.5, len(categories) - 0.2)  # 留空間給標籤
```

若仍需要圖例,將圖例放在資料附近（如圖內角落),搭配標題說明色階意義。

### 5. 邊線是可選,不是必要

色塊之間在實際圖表中通常**對比足夠**,不需要刻意加邊線。**只在以下情境考慮加白色邊線**：

- 列印用 PDF（解析度較低,邊界易模糊）
- 螢幕簡報的小型嵌入圖（圖表 < 400 px 寬）
- 色階位於低對比裝置（投影機/外接螢幕）顯示時

```python
# 一般情境:無邊線,視覺更乾淨
ax.bar(x, mild, color=mono3[0])
ax.bar(x, mod, bottom=mild, color=mono3[1])

# 列印/低對比情境:可加細白線
ax.bar(x, mild, color=mono3[0], edgecolor="white", linewidth=0.5)
```

### 6. 堆疊順序：最深色放底部

當資料維度有「強度／嚴重度」意義時，**最深色（代表最強）應放在堆疊底部**。設計理由：

- **視覺重量原則**：深色有「向下沉」的直覺重量,放底部視覺穩定
- **強度即基底**：「重症」這層成為視覺基準,跨類別的高度差一眼看出風險梯度
- **跨類別比較直觀**：例如年齡 × 嚴重度,「80+ 重症高度 vs 0-9 重症高度」的差距更易讀
- **呼應發散色階規範**：深色 = 重要端,堆疊基底也應如此

對應的堆疊順序（從底到頂）：

```python
# ✓ 正確:重症(深)在底,輕症(淺)在頂
ax.bar(x, severe,    color=mono3[2])              # 最深,在底
ax.bar(x, moderate,  bottom=severe, color=mono3[1])
ax.bar(x, mild, bottom=severe+moderate, color=mono3[0])  # 最淺,在頂

# ✗ 錯誤:輕症在底會讓「重症高度」變成從中間量起,讀起來費力
```

**圖例順序也要呼應**：matplotlib 預設按繪製順序排列圖例,堆疊底→頂剛好對應「強→弱」。
若想讓圖例改為「弱→強」更貼近列表習慣,可用 `handles[::-1]` 反轉。

### 7. 跨圖一致

同一份報告中，若某個指標用了單色（如嚴重度色階），所有相關圖表都該用同一組色階。讀者習慣「深色 = 重症」後，跨圖能直覺對應。

## 何時選單色 vs 何時選類別配色

| 情境 | 序列數 | 推薦 | 為什麼 |
|------|-------|------|--------|
| 嚴重度（輕／中／重） | 3 | `MONOCHROME["scale_3"]` | 序數,深淺對應強度 |
| 男 vs 女 | 2 | `MONOCHROME["focus_2"]` 或主色+輔色 | 少類別,克制視覺 |
| 22 縣市排名 | 22 | 單色主色 + Terracotta 標警示 | 類別太多,只區分焦點 |
| 6 種變異株 | 6 | 類別配色 | 並列無序,需明確區分 |
| 疫苗 1/2/3 劑覆蓋率 | 3 | `MONOCHROME["scale_3"]` | 序數遞進 |
| 三家醫院床位使用率 | 3 | 視情境:類別 或 `scale_3` | 想強調差異 → 類別;想看整體 → 單色 |
| 歷次 4 波疫情比較 | 4 | `MONOCHROME["scale_4"]`,當前波最深 | 時序自然有序 |
| 縣市發生率熱力圖 | 連續 | 序列色階 SEQUENTIAL | 連續變數需平滑色階 |
| 本機關 vs 其他機關平均 | 2 | `MONOCHROME["focus_2"]` | 焦點+對照 |
| 教育/社福/經發等部門 | 6 | 類別配色 | 並列無序,部門地位平等 |

## 程式碼範例

```python
import matplotlib.pyplot as plt
from epidemic_palette import (
    MONOCHROME, PRIMARY_DARKER, ACCENT, NEUTRAL, apply_style
)
apply_style()

# 範例 A: 單色堆疊長條（深色基底 + 直接標籤）
ages = ["0-9", "10-19", "20-39", "40-59", "60-69", "70-79", "80+"]
mild, mod, sev = [...], [...], [...]  # 各序列資料

colors_3 = MONOCHROME["scale_3"]
fig, ax = plt.subplots(figsize=(9, 4.5))
# 重症(最深)在底,作為視覺基底
ax.bar(ages, sev, color=colors_3[2], width=0.6)
ax.bar(ages, mod, bottom=sev, color=colors_3[1], width=0.6)
bot_mild = [a+b for a, b in zip(sev, mod)]
ax.bar(ages, mild, bottom=bot_mild, color=colors_3[0], width=0.6)

# 直接標籤取代圖例(放在最後一根長條右側)
last = len(ages) - 1
ax.text(last + 0.45, sev[-1]/2, "重症",
        va="center", color=NEUTRAL["700"], fontweight="bold")
ax.text(last + 0.45, sev[-1] + mod[-1]/2, "中症",
        va="center", color=NEUTRAL["700"])
ax.text(last + 0.45, sev[-1] + mod[-1] + mild[-1]/2, "輕症",
        va="center", color=NEUTRAL["700"])
ax.set_xlim(-0.5, len(ages) - 0.2)

# 範例 B: 單色多折線（波次比較,當前波最深最粗）
mono4 = MONOCHROME["scale_4"]
for (label, vals), c in zip(waves.items(), mono4):
    is_current = "本波" in label
    ax.plot(days, vals, color=c,
            linewidth=3 if is_current else 1.8,
            label=label)

# 範例 C: 焦點 + 對照(2 序列)
mono2 = MONOCHROME["focus_2"]
ax.plot(years, ours, color=mono2[0], linewidth=2.5,
        marker="o", label="本機關")
ax.plot(years, avg, color=mono2[1], linewidth=1.5,
        linestyle="--", label="同類機關平均")
```

## 常見錯誤

| ✗ 錯誤 | ✓ 正確 |
|--------|--------|
| 6 色以上類別硬擠進單色色階(明度差不夠分辨) | 改用類別配色或拆成多個小圖 |
| 色階方向倒過來(重症淺、輕症深) | 強度對應明度,深色=重 |
| 堆疊時把最深色放在頂部 | 最深色(重症)放在底部,作為視覺基底 |
| 6 階均勻分布(淺色互相難分) | 用本指引預設的 `scale_6`(中段拉開) |
| 報告中時而單色時而類別色(同指標) | 同指標跨圖一致用單色 |
| 認為「序數才能用單色」 | 2-3 組類別也可用單色,讓視覺更克制 |
| 為了「視覺豐富」把單色情境改用類別色 | 顏色服務於訊息,不為豐富而豐富 |
