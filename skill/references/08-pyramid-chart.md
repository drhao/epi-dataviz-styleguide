# 08. 人口金字塔（Population Pyramid）

> 雙向水平長條圖的特例。**疫情分析中最常用於呈現年齡 × 性別的分布**。

## 適用情境

| 情境 | 範例 |
|------|------|
| 年齡 × 性別 | 確診者、重症者、死亡者的年齡性別分布 |
| 暴露 × 對照 | 接種者 vs. 未接種者的年齡分布 |
| 時期比較 | 今年 vs. 去年的年齡結構 |

當兩組類別有**自然對立關係**（性別、有無暴露、實驗組對照組）且想看年齡分布時，金字塔比並排長條圖更直觀。

## 不適用情境

- 多於 2 組對比 → 改用分組長條或小倍數圖
- 類別非對立關係（如「自付 vs. 公費」與「年齡」無對立感）→ 改用一般直條圖

---

## 規範重點

### 1. 軸線設計

- **Y 軸**：年齡組（由下到上由幼至老）
- **X 軸**：人數，**左右兩側皆為正值**（左側為負數但顯示絕對值）

關鍵在 X 軸刻度的處理：

```python
ticks = [-30, -20, -10, 0, 10, 20, 30]
labels = ["30", "20", "10", "0", "10", "20", "30"]
ax.set_xticks(ticks)
ax.set_xticklabels(labels)  # 全部顯示為正值
```

中央的 0 是兩側的「共同基準」。

### 2. 顏色配置

- **左側（如男性）**：本指引主色 `#739A6D`
- **右側（如女性）**：類別配色第二色 `#587A9D`
- 不使用粉藍粉紅的傳統配色（過於刻板印象）

兩色須有足夠對比，色覺障礙者也能分辨。

### 3. 條的高度與間距

- `height = 0.75`（條較寬，因金字塔本身就有大量留白）
- 條間距由 height 自動產生
- 條之間用白色邊線 0.5 px 分隔

### 4. 中央分隔線

- Y 軸中央（X = 0）的垂直線
- 顏色 `Neutral 400`，linewidth 1
- 這條線是讀者左右比較的視覺基準

### 5. 左右側標籤

在 X 軸下方標註左右兩側代表的組別：

```python
ax.text(-17, -1.3, "← 男性", ha="center",
        color=PRIMARY_DARK, fontweight="bold")
ax.text(17, -1.3, "女性 →", ha="center",
        color=CATEGORICAL[1], fontweight="bold")
```

這比依賴圖例更直觀。

## 個別重點

### 年齡組劃分

疫情分析常用的年齡組（從窄到寬）：

- **每 10 歲一組**：`0–9, 10–19, ..., 80+`（最常用，9 組）
- **每 5 歲一組**：`0–4, 5–9, ..., 80+`（17 組，金字塔較細緻）
- **依風險族群**：`0–17, 18–49, 50–64, 65–74, 75+`

選擇原則：
- 對外公告、儀表板 → 10 歲一組（直覺易讀）
- 研究分析、學術發表 → 5 歲一組（資訊量更豐富）

最高組別必為「上限+」（如 80+），這是國際慣例。

### 對稱與不對稱

- **對稱金字塔**：呈現人口結構（如「美國 2020 年人口」）
- **不對稱金字塔**：兩組規模差異很大時（如重症者中女性顯著少於男性）

當兩組差異很大，**仍須使用相同的 X 軸刻度**（不可一側 0–30、另一側 0–100），否則會嚴重誤導比例感。

### 兩波次對比的特殊用法

呈現「同一性別在兩個波次的年齡分布變化」：
- 左側：第一波（淺色）
- 右側：第二波（主色）
- 同性別同年齡組可直接左右對讀

這比並列兩組金字塔更節省空間。

### 標籤策略

- 條的數值直接標於條外側（10+ 條時可只標重點組別）
- 對外報告：每組都標數值，方便讀者引用
- 內部分析：可省略，依賴 Y 軸刻度判讀

## 程式碼範例

```python
import numpy as np
import matplotlib.pyplot as plt
from epidemic_palette import (
    PRIMARY, PRIMARY_DARK, CATEGORICAL, NEUTRAL, apply_style
)
apply_style()

ages = ["0-9", "10-19", "20-29", "30-39", "40-49",
        "50-59", "60-69", "70-79", "80+"]
male   = [12, 18, 22, 24, 28, 30, 26, 18, 10]
female = [11, 17, 24, 26, 29, 31, 28, 22, 14]

fig, ax = plt.subplots(figsize=(8, 5.5))
y = np.arange(len(ages))

# 左側用負值
ax.barh(y, [-v for v in male], color=PRIMARY, height=0.75,
        label="男性", edgecolor="white", linewidth=0.5)
ax.barh(y, female, color=CATEGORICAL[1], height=0.75,
        label="女性", edgecolor="white", linewidth=0.5)

# Y 軸標籤
ax.set_yticks(y)
ax.set_yticklabels(ages)

# X 軸顯示絕對值
ax.set_xticks([-30, -20, -10, 0, 10, 20, 30])
ax.set_xticklabels(["30", "20", "10", "0", "10", "20", "30"])
ax.set_xlim(-35, 35)
ax.set_xlabel("確診人數（千人）")

# 中央分隔線
ax.axvline(0, color=NEUTRAL["400"], linewidth=1)

# 左右側標籤
ax.text(-17, -1.3, "← 男性", ha="center",
        color=PRIMARY_DARK, fontweight="bold")
ax.text(17, -1.3, "女性 →", ha="center",
        color=CATEGORICAL[1], fontweight="bold")
```

## 常見錯誤

| ✗ 錯誤 | ✓ 正確 |
|--------|--------|
| 左側 X 軸顯示負值（-30, -20...） | 顯示絕對值（30, 20, 10, 0, 10, 20...） |
| 兩側用不同尺度 | 必須相同尺度 |
| 用粉藍粉紅刻板配色 | 本指引主色 + 第二色 |
| 沒有中央分隔線 | 必畫 X = 0 垂直線 |
| 圖例位置遠離資料 | 直接在 X 軸下方加左右標籤 |
| 缺少最高組「80+」 | 須有上限「+」組 |
| 多於 2 組擠進金字塔 | 改用分組長條 |
