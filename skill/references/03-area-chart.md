# 03. 區域圖（Area Chart）

> 用於**強調「量的累積」隨時間的變化**。比折線圖更能凸顯規模感。

## 適用情境

| 情境 | 範例 |
|------|------|
| 累計值變化 | 累計確診數、累計疫苗接種劑次 |
| 強調量級 | 重症總人數的時間變化 |
| 與目標比較 | 進度條 + 目標線 |
| 多序列累積比較 | 1/2/3 劑覆蓋率隨時間 |

## 不適用情境

- 純比例變化（區域大小會誤導為「量」）→ 改用折線
- 多於 4 個系列且重疊嚴重 → 改用堆疊區域圖或折線圖
- 資料有負值 → 區域圖難以呈現負區間

---

## 規範重點

### 1. Y 軸必從零開始

區域圖呈現的是「面積」。截斷 Y 軸會嚴重扭曲面積感受。**這個規則比折線圖更嚴格**。

### 2. 填色透明度

- **單序列：** 主色填色 alpha `0.25`，線條保持實色
- **多序列：** 各序列填色 alpha `0.18–0.22`，線條使用加深版

透明度太低（< 0.15）難以辨識；太高（> 0.35）多序列疊加時會渾濁。

### 3. 邊線必須保留

填色區域的上邊線**必須以實色 2.5 px 描繪**，這條線是讀者實際對讀數值的依據。沒有邊線的純填色會讓讀者難以精確讀值。

### 4. 多序列疊加的順序

**由下而上**：數值較大或較重要的序列在下方（成為其他序列的「底」）。例如：
- 第 1 劑（最大）→ 第 2 劑 → 第 3 劑（最小）
- 高風險族群 → 中風險 → 低風險

### 5. 警戒線／目標線

- 目標線使用 `Alert Red #BE373C` 虛線
- 線寬 1.5 px
- 文字標籤「目標 X%」標於線右端

---

## 個別重點

### 單序列累計圖

最常見的用法。要點：
- 主色填色 + 主色加深邊線
- 在最新資料點顯示數值（大數字）
- 目標線在 Y 軸上的位置須讓讀者一眼看到「還差多遠」

### 多序列疊加（非堆疊）

各序列**獨立呈現**，互相重疊但不堆疊。適合呈現「不同人群的同一指標」（如各劑次接種率）。

- 半透明填色互相疊加
- 各邊線使用本指引的線條加深版
- 圖例置於下方水平排列，避免遮擋資料

### 堆疊區域圖

各序列**累加堆疊**，適合呈現「總量及其組成隨時間變化」。

- 注意：堆疊區域圖容易讓讀者誤解「上層序列的高度 = 該序列的值」（實際是該序列的「增量」）
- 若讀者主要關心比例變化，改用 100% 堆疊（百分比）
- 若主要關心個別序列的絕對值變化，**改用多條折線**

### 區域 vs. 折線的選擇

| 用途 | 圖式 |
|------|------|
| 比較精確數值 | 折線 |
| 強調量級感、累計感 | 區域 |
| 比較增長率 | 折線 |
| 比較總量規模 | 區域 |

## 程式碼範例

```python
import matplotlib.pyplot as plt
from epidemic_palette import (
    PRIMARY, PRIMARY_DARK, CATEGORICAL, LINE_COLORS,
    ACCENT, apply_style
)
apply_style()

# 單序列累計 + 目標線
months = ["1月", ..., "12月"]
cov = [42, 58, 71, ..., 94]

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.fill_between(months, 0, cov, color=PRIMARY, alpha=0.25)
ax.plot(months, cov, color=PRIMARY_DARK, linewidth=2.5,
        marker="o", markersize=4)
ax.axhline(y=90, color=ACCENT["alert"], linewidth=1.5,
           linestyle="--", label="目標 90%")
ax.set_ylim(0, 100)

# 多序列疊加（透明度堆疊）
ax.fill_between(x, 0, dose1, color=PRIMARY, alpha=0.22)
ax.plot(x, dose1, color=LINE_COLORS["primary"], linewidth=2.5)
ax.fill_between(x, 0, dose2, color=CATEGORICAL[1], alpha=0.22)
ax.plot(x, dose2, color=LINE_COLORS["blue"], linewidth=2.5)
```

## 相關規範

區域圖**多地區並排比較**(各縣市累計覆蓋率、各疫苗劑次跨組比較)時,套用 `M2-small-multiples.md`:統一 Y/X scale、共用圖例、focus panel 機制。

區域圖也常用於呈現 **不確定性區間**(信賴區間 / 預測區間),但兩者意義不同:

- **資料 area**(本檔規範):accumulated 數值或多序列疊加,**填色實體、邊線清晰**,讀者讀的是區域大小 = 量值
- **uncertainty area**(`M1-uncertainty-modifier.md`):點估計線上下的 CI 區間,**淺色 + 高 alpha 透明、無邊線**,讀者讀的是「真實值有 X% 機率落在帶內」

兩種視覺刻意拉開差異,避免讀者把 uncertainty 帶誤讀為「資料數量」。範例:`m1a-uncertainty-trailing-band.png`

## 常見錯誤

| ✗ 錯誤 | ✓ 正確 |
|--------|--------|
| Y 軸不從零開始 | 必從零開始（區域圖最嚴格） |
| 填色透明度 1.0（不透明） | 0.20–0.25 |
| 純填色無邊線 | 邊線實色 2.5 px |
| 4+ 序列疊加（混濁） | ≤ 3 序列，或改用其他圖式 |
| 堆疊區域被誤讀為個別值 | 改用多折線或 100% 堆疊 |
