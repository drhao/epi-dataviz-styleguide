# 04. 堆疊圖／分組圖（Stacked &amp; Grouped）

> 用於同時呈現「總量」與「組成」，或在兩個維度上比較資料。

## 子類型

| 圖式 | 用途 |
|------|------|
| 一般堆疊（值堆疊） | 同時看總量與內部組成 |
| 100% 堆疊（百分比） | 只看組成比例隨時間／類別的變化 |
| 水平堆疊條 | 圓餅圖的推薦替代（精確比較組成） |
| 分組長條（dodged） | 兩個維度的交叉比較 |

---

## 規範重點

### 1. 一般堆疊 vs. 100% 堆疊的選擇

- **一般堆疊**：當「總量本身」也是重要訊息時（例如各月確診數，且想看內部組成）
- **100% 堆疊**：當「比例變化」是重點，總量不重要時（例如變異株消長）

若同時想看總量與比例變化，**做兩張圖**比硬塞一張更清楚。

### 2. 類別數上限

- 一般堆疊：**最多 5 層**
- 100% 堆疊：**最多 6 層**
- 超過上限時，將次要類別合併為「其他」（用 `Neutral 300 #CACFC9`）

### 3. 顏色與堆疊順序

**由下至上**依本指引類別配色順序使用：cat-1 → cat-2 → ... → cat-N → 中性灰（其他）

- 主要對象、最大類別放最下方（視覺基底）
- 「其他」永遠在最上方

### 4. 圖例位置

- 圖例順序須與堆疊**由上至下對應**（圖例第一項 = 堆疊最上層）
  - 這是 matplotlib 預設行為的反向，要手動調整
- 圖例置於圖表上方（橫向排列）或右側（直向排列）

### 5. 100% 堆疊的特殊規則

- Y 軸固定 0–100，標籤加 `%`
- 可選擇性加上百分比標籤於各層中央（當層厚度 ≥ 8% 時）

---

## 個別重點

### 變異株 100% 堆疊（疫情經典圖式）

呈現病毒株消長最有效的圖表。要點：
- X 軸為時間（月或週）
- 每個 X 軸點為一個直條，內部按變異株比例堆疊
- 堆疊順序：最早出現的株在下、最新的在上
- 「其他」始終在最頂端，用中性灰
- 透過時間推移，可看出主流株如何被新株取代

### 水平堆疊條（圓餅圖替代）

當需要呈現「單一時點的組成比例」時，**優先使用水平堆疊條而非圓餅**。原因：
- 人眼比較「長度」遠比比較「扇形角度」精確
- 多列水平條可上下堆疊，比較不同群體或不同時期的組成
- 直接標籤可標於各區段內或下方

範例：今年 vs. 去年的接種狀態組成比較。

### 分組長條（Grouped / Dodged）

用於**兩個維度的交叉比較**。例如：
- 年齡層 × 嚴重度（X = 年齡層，分組 = 嚴重度）
- 地區 × 服務類型（X = 地區，分組 = 服務）

要點：
- **組內各條間留 1–2 px 細縫**（不可完全貼合，否則看似一根分色塊）
- **組間留更大空白**，明確區分不同主類別
- matplotlib 實作：條寬略小於偏移量，例如 `bar_w=0.23, offset=0.25`（三條時）
- 分組系列 ≤ 4 個，組數 ≤ 7 個（總數 ≤ 28 條）
- 系列順序依本指引類別配色

```python
# 三條分組（推薦比例）
bar_w = 0.23     # 條寬
offset = 0.25    # 中心偏移略大於條寬,留出細縫
ax.bar(x - offset, series_a, bar_w, color=CAT[0])
ax.bar(x,          series_b, bar_w, color=CAT[1])
ax.bar(x + offset, series_c, bar_w, color=CAT[2])
```

**錯誤示範**：`bar_w = 0.27, offset = 0.27`——三條剛好貼合無細縫，無法清楚區分系列。

### 一般堆疊 vs. 分組的選擇

| 目的 | 選擇 |
|------|------|
| 強調「總量」並看組成 | 一般堆疊 |
| 強調「比例」變化 | 100% 堆疊 |
| 強調「各系列的個別值」可比較 | 分組（dodged） |

當你的讀者主要關心「A 類別的這個數值與 B 類別的這個數值哪個大」，**分組比堆疊好讀**——因為人眼難以比較堆疊中「非最底層」的長度。

## 程式碼範例

```python
import numpy as np
import matplotlib.pyplot as plt
from epidemic_palette import CATEGORICAL, NEUTRAL, apply_style
apply_style()

# 100% 堆疊（變異株）
months = ["11月", "12月", "1月", "2月", "3月", "4月"]
jn1 = [62, 48, 32, 18, 8, 3]
kp2 = [28, 36, 42, 38, 24, 14]
# ...

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.bar(months, jn1, color=CATEGORICAL[0], width=0.6, label="JN.1")
ax.bar(months, kp2, bottom=jn1, color=CATEGORICAL[1], width=0.6, label="KP.2")
# 後續用 bottom = 累計值

# 分組長條
ages = ["0-9", "10-19", "20-39", ...]
x = np.arange(len(ages))
w = 0.27
ax.bar(x - w, mild, w, color=CATEGORICAL[0], label="輕症")
ax.bar(x,     mod,  w, color=CATEGORICAL[1], label="中症")
ax.bar(x + w, sev,  w, color=CATEGORICAL[2], label="重症")

# 水平堆疊條
ax.barh(rows, full, color=CATEGORICAL[0], height=0.6)
ax.barh(rows, partial, left=full, color=CATEGORICAL[1], height=0.6)
```

## 常見錯誤

| ✗ 錯誤 | ✓ 正確 |
|--------|--------|
| 堆疊超過 5 層 | 合併次要類別為「其他」 |
| 100% 堆疊 Y 軸超出 100% | 固定 0–100，加 `%` |
| 「其他」用鮮豔顏色 | 用 `Neutral 300` |
| 圖例順序與堆疊順序相反 | 圖例由上至下對應堆疊由上至下 |
| 想比較個別值卻用堆疊 | 改用分組長條 |
| 分組數 × 組數過多（混亂） | ≤ 4 × ≤ 7，超過用小倍數圖 |
